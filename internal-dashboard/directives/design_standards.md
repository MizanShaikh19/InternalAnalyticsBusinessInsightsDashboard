# Directive: Design Standards

This directive defines the visual and interaction standards for the Internal Analytics Dashboard.

## Visual Standards
- **Theme**: Sophisticated Dark Mode.
- **Background**: `radial-gradient(circle at top right, #1E293B, #0A0F1E)`.
- **Glassmorphism**: `backdrop-filter: blur(20px);` on all card elements.
- **Accents**: Use Electric Lime (`#AFE313`) for primary actions and highlights.

## Interaction Standards
- **Hover Effects**: All cards should scale slightly on hover (`scale(1.01)`) and increase border opacity.
- **Animations**: Use the `fadeIn` animation for main content and `slideInRight` for headers.
- **Feedback**: Provide immediate visual feedback for all user actions (e.g., button loading states, transition effects).
